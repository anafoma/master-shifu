# Intake questions

Ask these before writing a plan. Each answer changes a specific part of the programme. Skip any the user has already answered or that Hevy history makes obvious, and ask at most 3–4 at a time.

| # | Question | What it changes |
| --- | --- | --- |
| 1 | Main goal: hypertrophy, strength, or athletic/explosive? A split if mixed (e.g. 70/20/10) | Rep ranges, loads, proximity to failure, whether power work is included |
| 2 | Priority muscles, ranked in order (e.g. hamstrings, quads, calves, shoulders, glutes) | Which muscles get most weekly sets, go first in the session, get trained more often |
| 3 | Days per week at the gym | Split: full body, upper/lower, or push/pull/legs |
| 4 | Session length in minutes | How many working sets fit per session |
| 5 | Programme length: weeks before reassessing | Block structure, when to progress, when to rotate exercises |
| 6 | Training age and current lifts if known | Starting volume and loads |
| 7 | Equipment available | Exercise picks and swaps |
| 8 | Injuries, pain, or exercises to avoid | Exclusions and substitutions |
| 9 | Bodyweight trend and nutrition phase (gaining, losing, maintaining) | Volume tolerance; nutrition targets |

## Split by days per week

| Days | Default split |
| --- | --- |
| 2 | Full body ×2 |
| 3 | Full body ×3, or upper/lower/full |
| 4 | Upper/lower ×2 |
| 5 | Upper/lower + push/pull/legs, or a specialisation day for the top priority |
| 6 | Push/pull/legs ×2 |

## Saving the profile

Summarise the answers back as a short profile block and ask the user to confirm it. Reuse the profile in later conversations if it is available in context. Never ask for or store health details beyond what training needs (an injury to avoid is fine; diagnoses are not needed).

## Hevy shortcut

If Hevy is connected, read recent workouts and routines first: they reveal days per week, session length (start/end times), current loads, exercise preferences and the existing split. Then ask only what's missing.
